Right now, Falling Engine has a decent amount of features, like GLFT models, ECS, scripting, OpenGL rendering. However, it still needs a few things before I can start making games:
1. physics (currently in-progress!)
2. UI
3. scene management

As of now, I'm keeping it a code-only engine (there is some editor code left over from past experiments but I haven't updated it in forever), but I can forsee an editor at some point after all the core systems are
built.

Most people would say that making your own engine
is a waste of time, but something about me is that,
whenever possible, I like to understand the underlying
principles behind something I'm building on top of.

Follow along for updates!
